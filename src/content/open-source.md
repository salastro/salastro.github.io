Software that lets you read the argument, not just trust the conclusion. I care less about the license text and more about what it does to the work itself: bugs become public, decisions become traceable, and credit goes to whoever actually did the thing.

## Topics

- Contributing upstream instead of forking quietly
- Mentorship structures like GSoC as an on-ramp into real codebases
- Linux distributions as the clearest large-scale case study in open collaboration
- What changes about your code when strangers are allowed to read it

## Where It Shows Up

This is less a single project than a habit that runs through the others. It is the merged pull requests to Void Linux's installer and docs, the SymPy contributions that came out of GSoC, and the general preference for building in public over building in private.
